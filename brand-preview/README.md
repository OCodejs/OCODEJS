# OCodeJS Brand Preview

This folder contains an isolated, static UI preview for the OCodeJS website, authentication screens and developer console.

## Design tokens

- Background: `#000000` / `#09090B`
- Surfaces: `#121212` / `#18181B`
- Border: `#27272A`
- Primary text: `#FFFFFF`
- Secondary text: `#A1A1AA`
- Muted text: `#71717A`
- Headings and navigation: monospace
- Body: system sans-serif
- **All corners are square:** `border-radius: 0` for buttons, cards, inputs, panels and interactive controls.

## Included surfaces

- Website landing page and product sections: Mobile, Desktop, Terminal and SDK
- Core features: Free models, ocodejs Go, MCP servers, Plugins & Skills
- Documentation and community/resource footer links
- Signup and login UI with GitHub, Google, Apple and email presentation
- Console preview: Overview, Billing, API Keys and Team Management
- Responsive layouts for mobile and desktop

## Preview boundary

This is a frontend-only visual preview. OAuth, email authentication, billing, API key creation, invitations and provider connections are intentionally not wired to production services. No secrets or customer data are included.
